## 🚀 Características Principales

1. **Arquitectura Astro 5 & TypeScript Estricto**:
   - Componentes estáticos modulares ultra-ligeros con cero overhead en tiempo de ejecución.
   - Tipado estricto en interfaces de proyectos, métricas, competencias y contratos de datos.

2. **Diseño Visual & Experiencia de Usuario (UI/UX)**:
   - **Sistema de Maquetación "Un Solo Vistazo" (Viewport-Locked & Centered Section System)** en la sección de Contacto (`section-screen-fit`), eliminando scrolls innecesarios en monitores y laptops.
   - **Acordeón Vertical de Proyectos**: Despliegue interactivo de Case Studies con pipelines de arquitectura integrados de 4 pasos, mockups de navegador y accesibilidad completa por teclado (Home, End, Flechas).
   - **Ficha Técnica & Terminal Interactiva CLI**: Emulador de terminal con comandos rápidos ejecutables (`help`, `cat stack.json`, `git status`, `run benchmark`, `contact`, etc.) y respuestas en tiempo real.
   - **Internacionalización Bilingüe (i18n)**: Soporte completo e instantáneo Español / Inglés (ES / EN) en textos, pipelines, diagramas, metadatos y respuestas del CLI.
   - **Sistema de Temas (Dark / Light)**: Alternancia fluida con variables CSS y tokens Tailored HSL sin parpadeos (Zero FOUC).
   - **Modal Lightbox & Hover Previews**: Visualizador en alta resolución de capturas de proyectos con trampas de foco y navegación accesible.

3. **Accesibilidad Web (WCAG 2.2 AA)**:
   - Semántica HTML5 nativa, ratios de contraste verificados y anillos de foco visibles (`:focus-visible`).
   - Navegación mouse-free y compatibilidad completa con lectores de pantalla.

## 🛠️ Stack Tecnológico

- **Framework**: [Astro 5](https://astro.build/) (Static Site Generation / Islands Architecture)
- **Lenguaje**: [TypeScript](https://www.typescriptlang.org/)
- **Estilos**: [Tailwind CSS v4](https://tailwindcss.com/) + Vanilla CSS Custom Properties
- **Gestor de Paquetes**: [pnpm](https://pnpm.io/)
- **Optimización de Assets**: Sharp (generación automática de formatos WebP/AVIF)

## 💻 Desarrollo Local

```bash
# Instalar dependencias
pnpm install

# Iniciar servidor de desarrollo
pnpm run dev

# Compilar para producción
pnpm run build

# Previsualizar la versión de producción
pnpm run preview
```
